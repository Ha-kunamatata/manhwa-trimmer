만화 불러오기

시리즈 폴더 안에 화 폴더가 있고 그 안에 페이지 이미지가 있는 구조면 그대로 알아봅니다. 한 화 폴더만 골라도 됩니다. 아직 자르지 않은 긴 캡처라면 편집과 같은 방식으로 알아서 페이지를 찾아 읽어드려요.

토큰만 넣으면 읽을 수 있는 저장소를 알아서 찾습니다. 토큰은 이 기기의 브라우저에만 남고 GitHub 외에는 어디로도 가지 않아요.

토큰은 어떻게 만드나요?
  1. 토큰 만들기 화면을 엽니다
  2. Repository access → Only select repositories → 만화가 든 저장소를 고릅니다
  3. Permissions → Contents → Read-only
  4. 맨 아래 Generate token → 나온 값을 위에 붙여넣습니다

그 저장소를 읽는 것 말고는 아무것도 할 수 없는 토큰입니다.

어느 저장소를 읽을까요?

찾는 저장소가 없나요? 토큰에 그 저장소가 포함되지 않은 거예요. 토큰 설정에서 Repository access에 추가하고 다시 연결하세요.
